# Legacy Android distribution placeholder

This repository is retired in favor of product-based releases. Product APKs, public update metadata, and release notes should live in the corresponding product repository, such as [letsolo/lbv](https://github.com/letsolo/lbv).

No APKs were published here during initialization. History is retained, but no new product releases should target this platform repository. AAB uploads to Google Play remain private CI operations and are not installable public APK downloads.

The repository has no App private key or publishing credential. Its last maintained workflow uses a read-only Actions token to verify Vapor-authored commits and repository privacy.
